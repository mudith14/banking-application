Beginner: Basic Threads (Runnable, Thread lifecycle)

                
Creates a separate thread per deposit using BankingThreadFactory. Response shows thread name, ID, and state.

                

                    

                        
                        
                    

                    

                        
                        
                    

                

                

                    
                

            


            
            

                
Beginner: Synchronized + Lock Ordering (Deadlock Prevention)

                
Runs concurrent transfers with synchronized blocks. Locks acquired in lexicographic order to prevent deadlocks.

                

                    

                        
                        
                    

                    

                        
                        
                    

                    

                        
                        
                    

                

                

                    
                

            


            
            

                
Intermediate: Thread Pool + CountDownLatch (Batch Interest)

                
Uses ExecutorService fixed thread pool with CountDownLatch to calculate interest for all accounts in parallel.

                

                    
                

            


            
            

                
Intermediate: CompletableFuture (Async Transfer)

                
Chains async stages: validate → execute → log → result using thenApply/thenCompose. Failures handled with exceptionally().

                

                    

                        
                        
                    

                    

                        
                        
                    

                    

                        
                        
                    

                

                

                    
                

            


            
            

                
Intermediate: CyclicBarrier (Coordinated Settlement)

                
All transfer threads wait at a barrier before executing simultaneously, simulating a coordinated settlement.

                

                    

                        
                        
                    

                

                

                    
                

            


            
            

                
Intermediate: BlockingQueue (Producer-Consumer)

                
Enqueues a transaction to a bounded LinkedBlockingQueue. A background consumer thread processes it asynchronously.

                

                    

                        
                        
                    

                    

                        
                        
                    

                    

                        
                        
                    

                

                

                    
                

            


            
            

                
Intermediate: Semaphore (Rate Limiter)

                
Checks available permits in the Semaphore-based rate limiter that caps concurrent operations.

                

                    
                

            


            
            

                
Advanced: Fork/Join (Fraud Detection)

                
Uses ForkJoinPool with RecursiveTask to scan transactions in parallel. Flags amounts exceeding the threshold.

                

                    

                        
                        
                    

                

                

                    
                

            


            
            

                
Advanced: StampedLock (Optimistic Read)

                
Reads balance using optimistic read (no lock). Falls back to pessimistic read lock if a concurrent write invalidates the stamp.

                

                    

                        
                        
                    

                

                

                    
                

            


            
            

                
Advanced: Phaser (Multi-Phase Audit)

                
Three-phase audit: (1) collect snapshots, (2) validate balances, (3) generate report. Workers register/deregister dynamically.

                

                    
                

            


            
            

                
Advanced: Virtual Threads (Project Loom)

                
Attempts virtual threads via reflection (Java 21+), falls back to platform threads on Java 17. One thread per transfer.
